
# Gourmet Bites - Web Technologies Assignment 01

A fully responsive, 5-page static website for **Gourmet Bites** restaurant, built as part of the Web Technologies course under the instruction of **Dr. Noman Shafi**.

## 📌 Project Overview
This project showcases semantic HTML structure, modern CSS layouts (Flexbox & Grid), and dynamic JavaScript functionality with a complete Git branching workflow.

## 🚀 Pages Included
- **Home (`index.html`)**: Features hero section, image carousel, and highlights.
- **About Us (`about.html`)**: Restaurant story and core values.
- **Services (`services.html`)**: Interactive accordion for services and menu details.
- **Gallery (`gallery.html`)**: Food gallery organized with CSS Grid.
- **Contact Us (`contact.html`)**: Reservation form with real-time JavaScript validation.

## 🛠️ Tech Stack & Concepts Used
- **HTML5**: Semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- **CSS3**: Responsive design, CSS Flexbox, Grid, transitions, and hover effects.
- **JavaScript (ES6)**: Hamburger menu toggle, auto/manual image carousel, accordion collapse, and form validation.
- **Git & GitHub**: Version control using feature branching (`feature-navbar`, `feature-js-interactivity`).
